# Human-in-the-Loop Intervention Recommendation Framework

> **System**: PAIMANA PredictIQ — Decision Support Engine  
> **Module**: `app.services.intervention_engine`  
> **Author**: System Architect (SIH 26103)  

---

## 1. Non-Negotiable Core Architectural Constraint

```
========================================================================================
NON-NEGOTIABLE GOVERNANCE PRINCIPLE
----------------------------------------------------------------------------------------
The PAIMANA PredictIQ system MUST NEVER execute autonomous government actions, issue 
contractor penalties, or mandate budget reallocations independently. Every output 
generated by this engine exists strictly to INFORM human decision-makers, provide 
defensible evidence, and enforce explicit human approval gates.
========================================================================================
```

## 2. Risk Driver $\rightarrow$ Intervention Mapping Matrix

| Risk Signal / Driver Detected | Recommended Human Review Action | Expected Objective | Required Human Approver Role |
|---|---|---|---|
| **Milestone Slippage Rate ($\ge 20\%$)** | Technical Milestone Performance & Critical Path Audit | Establish revised critical path milestone baselines & deploy site engineers. | Ministry Project Sanctioning Committee / District Collector |
| **Persistent Progress Gap ($\ge 10\%$)** | On-Site Physical Execution & Resource Mobilization Review | Audit contractor labor force deployment, equipment, and supply chain bottlenecks. | Superintending Engineer / Nodal Officer |
| **Cost Acceleration ($\ge +10\%$)** | Financial Expenditure & Revised Cost Estimation Audit | Review item rate variances, unapproved scope additions, and price escalation. | Financial Advisor / Finance Committee |
| **Low Expenditure Velocity** | Fund Utilization & Disbursement Review | Expedite pending bill verifications and release capital disbursements. | Joint Secretary (Finance) |
| **Repeated Schedule Revisions** | Schedule Re-baselining & Contractor Delivery Audit | Comprehensive contractor capability audit & formal schedule re-baselining. | Project Director / Ministry Board |

## 3. Grounded Evidence Standard

PAIMANA PredictIQ enforces strict evidence grounding. Generic advice (e.g. *"Take corrective action"*) is prohibited. Every recommendation must cite concrete data:

- ❌ **Prohibited Generic Output**: *"Project is slipping. Review project progress."*
- ✅ **Enforced Grounded Output**: *"Milestone slippage rate reached 65.0% across 5 consecutive reporting cycles (exceeding the 20.0% threshold). Physical progress lags behind planned timeline by 18.5% (Predicted delay duration: 150 days)."*

## 4. Priority Calculation Methodology

$$\text{Priority Score} = \min\left(100.0, \text{round}\left( \left( 0.35 \cdot S_{\text{risk}} + 0.25 \cdot T_{\text{traj}} + 0.20 \cdot F_{\text{exp}} + 0.20 \cdot S_{\text{slip}} \right) \times 100 \times I_{\text{strat}}, 1 \right)\right)$$

### Factor Breakdown
1. **Risk Severity ($S_{\text{risk}}$)**: Direct model risk score ($[0.0, 1.0]$). Weight: **35%**.
2. **Risk Trajectory ($T_{\text{traj}}$)**: FSM state multiplier (`CRITICAL`/`ESCALATING` = 1.0, `HIGH_RISK` = 0.6, `WATCH` = 0.4). Weight: **25%**.
3. **Financial Exposure ($F_{\text{exp}}$)**: Budget at risk ($\text{Budget} \times \text{Cost Overrun \%}$ normalized). Weight: **20%**.
4. **Time Exposure ($S_{\text{slip}}$)**: Schedule slip magnitude normalized to 365 days. Weight: **20%**.
5. **Strategic Importance ($I_{\text{strat}}$)**: Ministry priority multiplier ($1.0 - 1.5$).

### Priority Classifications
- **`CRITICAL`**: Priority Score $\ge 80.0$ (Review Window: 3 Days)
- **`HIGH`**: Priority Score $\in [60.0, 79.9]$ (Review Window: 7 Days)
- **`MEDIUM`**: Priority Score $\in [40.0, 59.9]$ (Review Window: 14 Days)
- **`LOW`**: Priority Score $< 40.0$ (Review Window: 30 Days)

## 5. API Specification & Worked Examples

### `GET /api/v1/interventions/{project_id}`
Returns grounded, priority-ranked recommendations.

#### Example Response Payload:
```json
{
  "status": "success",
  "data": {
    "project_id": "P101",
    "total_recommendations": 1,
    "interventions": [
      {
        "recommendation_id": "REC_P101_MS_1756800000",
        "project_id": "P101",
        "priority_score": 84.5,
        "priority_level": "CRITICAL",
        "risk_driver": "Milestone Slippage Rate",
        "evidence": "Milestone slippage rate reached 45.0% across recent reporting cycles, exceeding the 20.0% governance threshold.",
        "recommended_action": "Convene a Technical Milestone Performance & Critical Path Audit with executive contractors.",
        "expected_objective": "Establish revised critical path milestone baselines and allocate site engineering personnel.",
        "review_window": "3 Days (Executive Escalation Window)",
        "confidence_score": 92.0,
        "human_approval_required": true,
        "approver_role": "Ministry Project Sanctioning Committee / District Magistrate",
        "status": "PROPOSED"
      }
    ]
  }
}
```

### `POST /api/v1/interventions/{recommendation_id}/approve`
Records human decision:
```json
{
  "new_status": "APPROVED",
  "reviewer_name": "Shri R.K. Sharma (Joint Secretary)",
  "reviewer_notes": "Approved technical audit team deployment for site inspection on Sep 5, 2026."
}
```
